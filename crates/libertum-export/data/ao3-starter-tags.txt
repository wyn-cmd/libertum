# AO3 starter additional tags (freeform tags)
#
# Format: one entry per line, "Tag Name | cue, cue, cue".
#   - Lines starting with '#' are comments; blank lines are ignored.
#   - Cues are lowercase single words that a chapter using the trope would plausibly contain.
#   - An entry with nothing after the '|' has no text cues; it is only ever suggested
#     from the user's learned history, never from chapter text.
#
# This is a hand-written starter list of commonly used AO3 additional tags, written
# from general knowledge (not copied from AO3 or any dataset). It is to be reviewed by
# hand. Spellings follow AO3's usual canonical forms as best known. Archive warnings
# and ratings are deliberately excluded.
