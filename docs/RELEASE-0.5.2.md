# Libertum 0.5.2

## Features

- **Vertical text.** **Document > Text Direction > Vertical** sets a document in columns that run from the right edge, as Chinese, Japanese and Korean books are set. Han, kana and Hangul stand upright; Latin and Cyrillic are turned a quarter turn; CJK punctuation, brackets and small kana take their vertical forms. Numbers stand upright a digit at a time (`2026`, `3.14`, `45%`), and a two-digit number such as the `11` in `11月` is set as one horizontal pair. Pictures keep their own shape, headers, footers and page numbers stay horizontal at the real top and bottom of the sheet, and a table whose cells hold plain text is laid out upright with its rows running down the sheet. Multiple text columns split the sheet into upper and lower blocks. Up and Down move along a column, Left and Right between columns. The direction is kept in Libertum, Word and OpenDocument files and in PDF exports; RTF, Markdown and HTML do not hold it.
- **Ruby.** Select text in one paragraph and type its reading in the Format pane's **Ruby** field: furigana for Japanese, pinyin for Chinese. The reading sits above horizontal text and to the right of a vertical column; a reading wider than its base spreads the base's letters to make room. Libertum, Word, OpenDocument and HTML keep it. RTF and Markdown drop the reading, and Markdown's lost-formatting report lists it.
- **Chinese, Japanese and Korean.** The Document pane's language list now has Chinese (Simplified), Chinese (Traditional), Japanese and Korean. Layout picks the regional font from the language, because the same Han character is drawn differently in each, and double-click, word movement and word delete use ICU4X's dictionary for an actual word (`北京`, `欢迎`) instead of one ideograph. The word count follows Word's rule: each ideograph and kana is a word, Hangul counts by space. The English checker no longer underlines Korean, kana or ideographs, and hyphenation is no longer applied to them. PDF export no longer leaves blank pages for the CFF2 fonts Fedora's Noto CJK ships: those glyphs are drawn as vector shapes, which look right but cannot be selected or searched; fonts with TrueType or ordinary CFF outlines still embed as text. The input-method composition string is measured, sits on a paper-coloured background and has a full-width underline.
- **A language per document, and a second one.** Spelling used to be a single global setting. Each document now keeps its own language, set in the Document pane and saved in Libertum, Word, OpenDocument and HTML files; RTF and Markdown cannot hold one, so the app remembers it by path. The Settings choice is now **Default language** and stamps new documents. A second, optional language lets one document hold two: a word is flagged only when every dictionary that judges it agrees, so Ukrainian and English in the same file check separately instead of hiding each other's mistakes. The pair is kept in the same four formats and remembered by path for RTF and Markdown.
- **A leaner spell checker, with Ukrainian and Russian.** `spellbook` replaces `zspell`. English grows memory by about 3 MB instead of 45, Russian by 16 MB instead of 435, and Ukrainian now loads at all (about 37 MB); dictionaries for both are bundled, with their licences. A dictionary checks only words in its own script, so an English word in a Ukrainian paragraph is not underlined by the Ukrainian one. The dictionary is still built off the UI thread and reused.
- **Linked pictures and videos.** **Insert > Linked Image or Video…** adds an online picture or video by its address, with a description and a choice of image or video. The page shows a drawn placeholder, or a preview you ask to download once with the system `curl`; a YouTube address gives its thumbnail. Nothing is fetched unless you tick the preview box or press **Fetch Preview**. The AO3 chapter HTML points at the address: `<img>` for a picture, `<video controls>` for a video file, a link for any other video. Libertum, Word and OpenDocument keep the address as the picture's name; Markdown writes `![description](address)` for a picture and a link for a video. The Format pane shows the kind and address and can fetch the preview again without changing the width.
- **Ukrainian hyphenation.** Ukrainian words wrap with the MIT-licensed `hyph-uk.tex` patterns. Russian patterns are LPPL, so Russian is still wrapped at spaces only.

## Changes

- **Shortcuts.** Cmd/Ctrl+N opens the home screen to pick a template, and Cmd/Ctrl+Alt+1 to 4 apply Heading 1 to 4 while Cmd/Ctrl+Alt+0 applies body text. Every shortcut now works on a Cyrillic, Greek or other non-Latin keyboard layout: while Ctrl or Cmd is held, the key is read by its physical position instead of the layout's letter, so Ctrl+C still copies when the layout reports `с`. Latin layouts are untouched.
- **Document pane.** The sidebar is 320 points, so the Position buttons no longer clip. Page Colour and Watermark appear only for formats that keep them, with their long captions removed. The page-colour swatches use the app's pill tooltip.
- **Spelling words.** `spellbook` has no word iterator, so the app splits text itself: letters, digits and combining marks, with an apostrophe or hyphen kept inside a word (`don't`, `well-known`). A word with a digit is skipped, and a hyphenated word is accepted whole or part by part. Each dictionary judges only words in its own script, so an English word in a Ukrainian paragraph is not underlined by the Ukrainian dictionary.
- **Faster frames.** Iced's window-wide 4x MSAA is off: it only smooths `canvas` geometry, which Libertum does not draw, so every frame was paying for a 4x colour buffer and a resolve pass. Screenshots of the main views in both themes were pixel-identical with it on and off.
- **Dependencies.** New: `spellbook` 0.4.2 (MPL-2.0) for spelling, `icu_segmenter` 2.4 (Unicode-3.0) for Chinese and Japanese word boundaries, and the Ukrainian `hypher` patterns. `zspell` is gone. `docs/third-party-licences.md`, the README's acknowledgements and the bundled dictionary licence files are updated.

## Packaging

- Windows: `Libertum-Setup.exe` and `Libertum-Setup-0.5.2.exe`.
- Linux: `.deb`, `.rpm` and `.AppImage`.
- macOS: `.dmg` and `.zip` for Apple Silicon and Intel.
- `SHA256SUMS` covers every attached file.
- Existing installations are offered 0.5.2 by the in-app updater; on Linux the `.deb` and `.rpm` install themselves through the desktop's administrator prompt.

## Notes

- Builds are unsigned. Windows SmartScreen may warn on first run; on macOS, right-click the app and choose **Open**.
- Vertical text, ruby and upright tables have round-trip tests but have not been opened in Word or LibreOffice. Opening one of each in both is the first thing to check.
- No real input method was driven: composing with ibus Hangul, Pinyin or Anthy, and where the candidate window appears, are unchecked.
- On a vertical page, a table with pictures, list items, cell borders or contents targets still turns with the page, and the headers and footers do not do vertical running heads down the side. `tb-lr` (Mongolian) reads as horizontal, and the decimal point in `3.14` sits a little close to the next digit.
- Whether AO3 accepts `<video>` is unverified. Test one chapter before relying on it; a stripped video leaves nothing, and the link form is the fallback.
- A language remembered for an RTF or Markdown file is lost if the file is moved or renamed. Chinese, Japanese and Korean have no dictionary, so a document in one of them is not spell-checked.
- Only three things use the network: the daily update check, an MCP client you turn on, and a linked preview you ask to download. Nothing about a document is sent.
- No document format changed incompatibly; files opened and saved by 0.5.1 still open.
